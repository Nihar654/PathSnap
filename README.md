# PathSnap ML Project

This repository contains the minimal solution for the PathSnap machine‑learning hackathon.

## Directory layout
```
PathSnap_project/
├─ data/                # original CSV files (train.csv, test.csv)
├─ notebooks/           # exploratory notebooks
│   └─ PathSnap_solution.ipynb   # full end‑to‑end pipeline (provided)
├─ src/                 # reusable Python modules
│   ├─ preprocessing.py # data cleaning & feature engineering
│   ├─ model.py         # model training & evaluation
│   ├─ predict.py       # generate predictions for test set
│   ├─ bayes_opt.py     # Bayesian optimisation (Member 2)
│   └─ hmm_verify.py    # HMM/Viterbi verification (Member 2)
├─ submission/          # final deliverables (predictions, report, logs)
│   ├─ predictions.csv  # generated by notebook / scripts
│   └─ report.md        # short markdown report
├─ api/                 # FastAPI server (Member 3)
│   ├─ api_app.py       # FastAPI implementation
│   └─ index.html       # simple UI for testing
├─ requirements.txt     # Python dependencies
└─ README.md            # this file
```

## How to run
1. **Install Python 3** (ensure it is on your `PATH`).
2. Install dependencies:
   ```
   python -m pip install -r requirements.txt
   ```
3. Run the notebook (`notebooks/PathSnap_solution.ipynb`) **or** the scripts in `src/`.
4. To serve the API (Member 3):
   ```
   cd api
   uvicorn api_app:app --reload --port 8000
   ```
   Then open `api/index.html` (or serve it via `python -m http.server`).
5. Verify `submission/predictions.csv` and `submission/report.md` exist and zip the `submission/` folder for the final deliverable.

---
### Notes
* The notebook contains a baseline Random Forest model; you can replace it with the Bayesian‑optimised model (`submission/model.pkl`).
* All file paths in the scripts are relative to the repository root.
* The `requirements.txt` pins versions known to work on Windows.
